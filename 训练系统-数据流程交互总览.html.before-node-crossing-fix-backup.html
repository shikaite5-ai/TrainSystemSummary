4. 如何阅读

先看数据平面：输入经过前向、损失和反向，最终形成梯度；再看更新状态：梯度结合 FP32 主权重和 Adam 状态完成更新；最后看控制平面：step、学习率、分片布局、通信配置和版本状态决定数据何时以及如何流动。
